# Piyingxi shadowing tool

Piyingxi (皮影戏) is a shadowing tool for learners of tonal languages. It is written in Java and is built from source on a machine that has JDK installed using:

javac -cp jlayer-1.0.1.4.jar:flatlaf-3.5.4.jar Piyingxi.java

jar cfm piyingxi.jar manifest.txt *.class

Piyingxi integrates audio shadowing capabilities with pitch and tone visualisation to address the needs of tonal language learners in the classroom and in independent study.
